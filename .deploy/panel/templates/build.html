Windows 目标需要一台构建机

Flutter 不支持在 Linux 上构建 Windows 客户端，所以 Windows 目标走 agent 模式： 面板派发任务 -> Windows 构建机编译 -> 产物自动回传 -> 你在面板上下载。

在 Windows 构建机上跑（agent 源码在客户端仓库的 tools/ 或随包分发的 builder/agent.py）：

python builder\agent.py --panel http://<服务器IP>:21120 --token <agent_token>

agent_token 在服务器的 /etc/rustdesk-panel/panel.conf 里， 安装时生成，也可以看 cat /etc/rustdesk-panel/panel.conf。 构建机需要预装：Rust 工具链、vcpkg 依赖（libvpx/libyuv/opus/aom）、Flutter SDK。
